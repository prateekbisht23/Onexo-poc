How the stored token reaches Kong — and where it stops

Claude gets only a helper key at launch. Its apiKeyHelper trades the key at the POC broker for the user's current OneXO token, refreshed first if it is near expiry (rotating, so the row is overwritten). Claude sends it as a bearer to Kong; Connectra meters the call as the user and calls Bifrost with its own key — the user token never goes further.

Repeats every GATEWAY_TOKEN_REFRESH_S=600 and after any 401 · session end: broker.close() deletes the helper key · /logout deletes the logins row
