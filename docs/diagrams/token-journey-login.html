Where the OneXO token is born and first stored

Typing /login and choosing OneXO runs OneXO's authorization-code + PKCE flow. The first token has no tenant and lives only in POC memory; after the tenant pick the POC swaps it for a tenant token and writes it to chats.db. OneXO keeps only a hash of the refresh token in Redis.

Code: index.ts handleLogin · handleOnexoCallback · finishOnexoLogin → auth/onexo.ts exchangeCode · refreshTokens → auth/logins.ts saveOnexoLogin → db.ts saveLogin
