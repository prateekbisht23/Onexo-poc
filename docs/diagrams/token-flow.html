Sequence · token mint, call, recovery

How the harness gets tokens, calls the gateway, and fails visibly

After “/login → OneXO”, the POC holds the user's OneXO refresh token. Claude CLI's apiKeyHelper trades a per-session key at the POC broker for that user's current 900-second token — refreshed one at a time per user, because OneXO rotates refresh tokens — re-running it every 10 minutes and on any 401. A gateway refusal that is not about the token trips the broker's storm guard instead of retrying for minutes.

Refresh every GATEWAY_TOKEN_REFRESH_S=600 · token TTL 900s · storm guard: ≥4 helper calls in 30s
