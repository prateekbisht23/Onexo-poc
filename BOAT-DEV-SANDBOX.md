# boat.dev Sandbox: Quick Overview

## Pricing

- You pay **per second, only while a sandbox is running**. A stopped sandbox is free and keeps its files.
- **Default machine** (4 CPU / 8 GB): **$0.036/hour**
- **Large machine** (8 CPU / 16 GB): **$0.072/hour**
- The monthly plan ($20 / $100 / $500 / $2000) is not a fee. It comes back as usage time, and a bigger plan lets more sandboxes run and start at once.

| Scenario | Monthly cost |
|---|---|
| 50 users · 3 h/day | **~$119** |
| 100 users · 3 h/day | **~$238** |
| 50 users · 8 h/day | **~$317** |
| 50 users · 24/7 · large machine | **~$2,628** |

The first three assume 22 working days a month. If users work all 30 days: $162 / $324 / $432.
